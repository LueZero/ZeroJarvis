全流程：建立筆記本 → 加來源 → 產生測驗 → 互動
【第一句】建立筆記本

🗣️ 「賈維斯，幫我建一個新筆記本叫做 AI 學習筆記」

預期 Jarvis 回應：「好的，已經幫你建立了『AI 學習筆記』筆記本。」

【第二句】新增來源

🗣️ 「把這個網址加進去：https://en.wikipedia.org/wiki/Transformer_(deep_learning_model)」

預期 Jarvis 回應：「已經加入來源了，是一篇關於 Transformer 模型的維基百科文章。」

【第三句】再加一個來源

🗣️ 「再加一個 https://en.wikipedia.org/wiki/Large_language_model」

預期 Jarvis 回應：「好，大型語言模型的文章也加進去了。」

【第四句】產生測驗

🗣️ 「幫我根據筆記本內容出個測驗，中等難度」

預期 Jarvis 回應：「好的，正在幫你產生測驗題，稍等一下。」
（等待 1-5 分鐘）
→ 產生完成後語音：「五題測驗產生好了，顯示在畫面上。」
→ NotebookOverlay 滑入，顯示 Quiz 卡片

【第五句】互動問答（看著 overlay 問）

🗣️ 「第二題為什麼答案是那個？」

預期 Jarvis 回應：「根據筆記本的資料，因為 Transformer 的核心是 self-attention 機制...（解說）」

【第六句】關閉

🗣️ 「好了，關掉測驗」

預期 Jarvis 回應：「好的。」
→ overlay 滑出消失
