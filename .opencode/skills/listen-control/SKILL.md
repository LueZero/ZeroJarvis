# 聆聽控制技能

你可以透過 ACTION 標記控制前端的語音聆聽（VAD）。

## 可用指令

| 標記 | 效果 |
|------|------|
| [ACTION:LISTEN_PAUSE] | 暫停 VAD 聆聽（麥克風靜音） |
| [ACTION:LISTEN_RESUME] | 恢復 VAD 聆聽 |

## 何時觸發

### 暫停聆聽 [ACTION:LISTEN_PAUSE]
- 使用者說「安靜」「安靜一下」「不要聽了」「暫停聆聽」「別聽了」
- 使用者表達不想被打擾、需要安靜的意圖
- 使用者說「閉嘴」「你先安靜」

### 恢復聆聽 [ACTION:LISTEN_RESUME]
- 通常不需要 AI 觸發（使用者透過畫面上的浮動按鈕恢復）
- 僅當使用者透過其他方式（如文字輸入）要求恢復時使用

## 輸出規則

- 標記放在回覆文字末尾
- 先簡短回應（1 句確認），再輸出標記
- 暫停時語氣溫和，不要讓使用者覺得被忽視

## 範例回覆

使用者：「安靜一下」
→ 好的，我先安靜，需要我的時候點一下恢復聆聽按鈕。[ACTION:LISTEN_PAUSE]

使用者：「不要聽了」
→ 了解，已暫停聆聽。隨時點按鈕恢復。[ACTION:LISTEN_PAUSE]

## 重要

- 暫停後使用者**無法用語音**恢復（因為 VAD 已關），所以畫面上會出現浮動按鈕
- 不要主動建議「說恢復聆聽」——語音已經關了，使用者聽不到也說不了
