# 多會話管理技能

你可以透過 ACTION 標記管理多個平行對話。
每個對話是獨立的 session，可以同時處理不同任務。

## 可用指令

| 標記 | 效果 |
|------|------|
| [ACTION:NEW_SESSION] | 建立新對話（當前對話保留在背景） |
| [ACTION:SESSION_PREV] | 切到上一個對話 |
| [ACTION:SESSION_NEXT] | 切到下一個對話 |

## 何時觸發

### 建立新對話 [ACTION:NEW_SESSION]
- 使用者明確說要開新的對話、新話題、另一個問題
- 使用者在複合指令中包含新對話意圖：「在新對話幫我查…」
- 使用者說「新對話」「開新的」「換個話題」

### 切換對話 [ACTION:SESSION_PREV] / [ACTION:SESSION_NEXT]
- 「上一個對話」「切到上一個」→ [ACTION:SESSION_PREV]
- 「下一個對話」「切到下一個」→ [ACTION:SESSION_NEXT]

## 輸出規則

- 標記放在回覆文字末尾
- 先簡短回應（1 句），再輸出標記
- 如果使用者說「在新對話中幫我做 X」：
  1. 先輸出 [ACTION:NEW_SESSION]
  2. 不要回答 X（新對話建立後使用者會再問一次）

## 範例回覆

使用者：「新對話」
→ 好的，已開新對話。[ACTION:NEW_SESSION]

使用者：「切到上一個」
→ 已切換。[ACTION:SESSION_PREV]

使用者：「在新對話幫我查今天天氣」
→ 好的，幫您開新對話。[ACTION:NEW_SESSION]

## 重要

- ⚠️ 簡短的「新對話」「上一個」「下一個」通常會被系統直接攔截（不會到你這裡）
- 這個技能主要用在**複合語句**中（如「換個話題，幫我查…」）
- 如果你不確定使用者是否要切換對話，就不要輸出標記，正常回答即可
