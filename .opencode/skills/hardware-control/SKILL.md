# 硬體控制技能

你可以透過在回覆中輸出 ACTION 標記來控制使用者的實體裝置。
系統會自動解析標記並執行對應動作，標記本身不會顯示給使用者。

## 可用指令

| 標記 | 效果 |
|------|------|
| [ACTION:CAMERA_ON] | 開啟攝像頭 |
| [ACTION:CAMERA_OFF] | 關閉攝像頭 |
| [ACTION:CAPTURE] | 擷取當前攝像頭畫面並送交視覺分析 |

## 輸出規則

- 標記放在回覆文字末尾
- 不加引號、反引號、或任何包裝字元
- 可以在一個回覆中輸出多個標記
- 格式嚴格為 `[ACTION:大寫名稱]`

## 何時觸發

- 使用者要求開啟/關閉攝像頭 → CAMERA_ON 或 CAMERA_OFF
- 使用者要求拍照、照相、截圖、擷取畫面、看一下 → CAPTURE
- 使用者要求照相分析 → CAMERA_ON + CAPTURE（若攝像頭未開）

## 重要

- 你「說」了不等於你做了。必須輸出標記才會真正觸發動作。
- 如果使用者要求拍照，你的回覆**必須**包含 [ACTION:CAPTURE]，否則什麼都不會發生。
- CAPTURE 後系統會自動呼叫 vision 子代理分析圖片，你不需要自己分析。
- ⚠️ 絕對不要回覆「截圖失敗」「圖片未傳送」「無法接收圖片」之類的話。你無法看到圖片，你只需輸出標記讓系統去處理。
- 當使用者說「截圖」「拍照」「看看」「分析畫面」「幫我拍」等任何拍照相關語句時，無條件輸出 [ACTION:CAPTURE]。

## 範例回覆

使用者：「開鏡頭」
→ 正在開啟。[ACTION:CAMERA_ON]

使用者：「拍張照看看」
→ 正在擷取畫面。[ACTION:CAPTURE]

使用者：「幫我照相分析裡面有什麼數字」
→ 正在擷取畫面進行分析。[ACTION:CAPTURE]

使用者：「幫我截圖並分析圖片裡面的內容是什麼」
→ 正在擷取分析。[ACTION:CAPTURE]

使用者：「看看現在鏡頭拍到什麼」
→ 正在為您截圖分析。[ACTION:CAPTURE]

使用者：「關掉攝像頭」
→ 已關閉。[ACTION:CAMERA_OFF]
