# 螢幕截圖技能

你可以透過 ACTION 標記擷取使用者的電腦螢幕畫面，並交由 vision 子代理分析。

## 可用指令

| 標記 | 效果 |
|------|------|
| [ACTION:SCREENSHOT] | 擷取電腦螢幕全畫面，送交視覺分析 |

## 與 CAPTURE 的差異

| | CAPTURE | SCREENSHOT |
|---|---|---|
| 來源 | 攝像頭（拍照） | 電腦螢幕 |
| 用途 | 看實體物品/環境 | 看螢幕內容/程式畫面 |
| 需要攝像頭 | 是 | 否 |

## 何時觸發

使用者表達以下意圖時，輸出 `[ACTION:SCREENSHOT]`：
- 「截圖」「螢幕截圖」「幫我看螢幕」「看一下我的畫面」
- 「分析我螢幕上的東西」「螢幕上寫什麼」
- 「幫我看這個頁面」「看看我現在開什麼」
- 「screen capture」「take a screenshot」

## 何時不觸發（用 CAPTURE）

使用者表達以下意圖時，用 CAPTURE 而非 SCREENSHOT：
- 「拍照」「照相」「看看前面」「鏡頭拍到什麼」
- 涉及實體環境、物品、人

## 輸出規則

- 標記放在回覆文字末尾
- 不加引號、反引號、或任何包裝字元
- 格式嚴格為 `[ACTION:SCREENSHOT]`

## 重要

- 你「說」了不等於你做了。必須輸出標記才會真正觸發截圖。
- 截圖後系統自動呼叫 vision 子代理分析，你不需要自己分析。
- ⚠️ 絕對不要回覆「截圖失敗」「無法取得畫面」之類的話。
- Desktop 模式下截圖是即時的（無需使用者確認）。
- Web 模式下瀏覽器會跳出分享畫面的授權提示。

## 範例回覆

使用者：「幫我截圖看一下螢幕」
→ 正在擷取螢幕畫面。[ACTION:SCREENSHOT]

使用者：「螢幕上這個錯誤訊息什麼意思？」
→ 讓我看看。[ACTION:SCREENSHOT]

使用者：「分析一下我現在的畫面」
→ 正在截取螢幕。[ACTION:SCREENSHOT]

使用者：「幫我看看這個網頁寫什麼」
→ 正在擷取畫面分析。[ACTION:SCREENSHOT]
